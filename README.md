# Midwest Esports League Tournament Manager

## Project Overview

The Midwest Esports League Tournament Manager is a web application designed to simplify the organization and management of esports tournaments.

The application will allow players to register for upcoming tournaments while providing organizers with tools to manage registrations, track attendance, and confirm payments.

The goal is to create a simple, reliable, and secure system that improves the tournament experience for both players and organizers.

## Planned Features

- Player registration for upcoming tournaments
- Tournament creation and management
- Player check-in and attendance tracking
- Manual payment confirmation
- Administrative dashboard for tournament organizers
- Security controls to protect player information

## Technologies

- Python
- Django
- PostgreSQL
- Docker
- HTML/CSS
